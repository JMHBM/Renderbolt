# Looks

Shareable JSON. Load in the studio or pass `--look` on `main` (1.0.7, unreleased).

| File | Vibe |
|---|---|
| night-drive.json | 3D waveform, midnight, 16:9 |
| live-session.json | 2D EQ, ember |
| vinyl.json | 3D circular, gold, square |
| after-hours.json | 3D liquid, violet |
| neon-rain.json | 3D EQ, cyan, 9:16 |
| broadcast.json | 2D waveform, mono |

Keys **1–6** in the studio. Files live in [`looks/`](https://github.com/JMHBM/Renderbolt/tree/main/looks) on `main`.

The GitHub Release `.deb` is still **1.0.6** and does not include these files.
